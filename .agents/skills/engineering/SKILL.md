Load only the changed surface:

- TypeScript/JavaScript shape, naming, identity, control flow, or abstraction → `references/code.md`
- Manifests, dependencies, packages, exports, scripts, generated files, lockfiles, or Vite Plus → `references/workspace.md`
- Effect, Schema, services, errors, resources, streams, tracing, or native boundaries → `references/effect.md`
- Router, RPC, Atom, React, or frontend state → `references/react.md`
- Automated-test implementation or Effect test mechanics → `references/testing.md`
- Product interaction, feedback, accessibility, layout, components, styling, or copy → `references/ui-design.md`

Treat every loaded rule as a diagnostic: correct its owning design problem, not its visible symptom.
