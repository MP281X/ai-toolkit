## Own

| Owner                  | Surface                                                                                     |
| ---------------------- | ------------------------------------------------------------------------------------------- |
| `AGENTS.md`            | unconditional authority hierarchy, vocabulary, and user-visible writing                     |
| Metadata `name`        | canonical identifier                                                                        |
| Metadata `description` | sole exact trigger and capability                                                           |
| Native agent body      | role-local construction, invariants, exact operational procedure, and output                |
| Domain skill body      | conditional architecture, semantics, intent, canonical construction, and output             |
| Skill reference        | one genuinely conditional branch omitted from the skill body                                |
| Codex configuration    | project and global configuration policy; never authority to mutate external or global state |
| Static enforcement     | safely detectable validity, syntax, formatting, semantics, and graph constraints            |

Keep routing and selection in descriptions. Skill bodies may route directly to genuinely conditional references. Native agent bodies never own progressive discovery or reference-loading rules. Do not repeat metadata meaning in a body.

## Retain

Keep skill guidance only when the pattern is frequent, architectural, or routinely misfixed from diagnostics alone. Prefer an existing maintained enforcement rule before custom enforcement.

## Output

Return only the requested enforcement or instruction artifact, material failures, earliest shared causes, corrections, changed holdout results, and semantic delta.
