---
name: iteration
description: 'Use when requirements, design, scope, or feedback remain unresolved during planning, review, steering, or reconciliation.'
---

| Lead     | Requirement                                                                                                                                                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Verify   | Treat requested behavior and preferences as authority. Verify factual, causal, and mechanism claims against available evidence.                                                                                                            |
| Resolve  | Before a question or proposal, use delegated evidence to resolve applicable facts from the discussion, Workflow, repository, configuration, history, CLI, and configured references.                                                       |
| Design   | Load applicable domain skills before proposing files, ownership, interfaces, schemas, lifecycle, failures, performance, proof, or exclusions.                                                                                              |
| Question | Ask only unresolved questions that can change the experiment. Ask independent questions together.                                                                                                                                          |
| Propose  | Present the smallest concrete Construction. Include affected Owners and Coupled paths, final public interfaces and schemas, lifecycle, reachable failures, performance, proof, and material exclusions only when they change the decision. |
| Defer    | Keep unrequested possibilities outside the active proposal unless the user selects them.                                                                                                                                                   |

## Collaboration

| Condition                                        | Required action                                | Forbidden action             |
| ------------------------------------------------ | ---------------------------------------------- | ---------------------------- |
| Unresolved requirement or design                 | Keep the question beside the blocked decision. | Continue with an assumption. |
| Approved Contract needs a material design change | Return the changed design for approval.        | Edit before approval.        |
